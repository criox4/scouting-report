# Surface: wallet lookup + trader report

Scope: `/` (blank report form: wallet entry) and `/[chain]/[wallet]` (filed report). Visitor mode: Operate.
Audience/job: copy-trade scouts judging whether a wallet is worth following, in under a minute.
Proof/content: real tracker output only (src/). Limits shown, never hidden.
Constraints: first lookup can take ~1–2 min; progress must be honest (streamed stages).

## Direction contract

THESIS: Each wallet is filed as a scout's report on the 20–80 scale: a verdict and graded tools first, typed evidence after. Refuses the dark crypto dashboard (portfolio number + chart + panels).

OWN-WORLD: Canary carbonless form paper (#F6EFA6-family) ruled by 1px carbon-blue field boxes that ARE the layout grid; typed entries in carbon blue; one red rubber stamp per report for the verdict; pen-circled grades. Carbon blue owns every live state. Closed positions struck through, focus bracketed. Dark variant: blue-black carbon sheet with pale ink.

STORY: Visitor pastes a wallet, watches the report get filed stage by stage, reads the overall grade + stamp, checks the tool grades and the evidence behind each, then scans holdings, best calls, and the swap log. Method and limits printed at the foot.

FIRST VIEWPORT: Report header strip (form title, subject wallet, chain, period, filed time) across the top; left two-thirds: the overall grade at poster scale on the printed 20·30·40·50·60·70·80 scale with a pen loop around it and the stamped verdict; right third: tool-grade rows each with its own scale and the stat behind it. Totals line under. Primary action (new lookup) lives in the header field.

FORM: Scouting Report dossier, position 3 on the ordered list; seed key 6b451897. Signature interaction: the pen loop draws around each grade as the report files.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
